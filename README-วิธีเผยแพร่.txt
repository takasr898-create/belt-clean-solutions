BELT & CLEAN SOLUTIONS — WEBSITE STARTER
=========================================

Files:
- index.html : complete responsive Thai-language website

How to preview:
1. Extract the ZIP (if downloaded as ZIP).
2. Double-click index.html to open it in Chrome.

Publish free with Netlify Drop:
1. Go to https://app.netlify.com/drop
2. Sign in or create a free account if prompted.
3. Drag the folder containing index.html onto the page (or drag the ZIP if accepted).
4. Netlify will publish a public URL. Open that URL on your phone to test.
5. You can change the site name in Netlify site settings if the name is available.

Alternative free publishing with GitHub Pages:
1. Create/sign in to https://github.com
2. Create a public repository, e.g. belt-clean-solutions
3. Upload index.html to the repository root.
4. Open Settings > Pages, select Deploy from a branch, choose main and /(root), then Save.
5. Wait for GitHub Pages to provide the public URL.

Before sharing publicly:
- Confirm LINE link works on your device. Some LINE accounts may need a different URL format; if it doesn't open the correct account, replace the LINE links in index.html with your official LINE link.
- Add real product photos and verify each product/service claim.
- Add business address and email if appropriate.
- Create/verify Google Business Profile if eligible, and add the final website URL.
- Register the website in Google Search Console and submit the sitemap if you later add one. Indexing is not instant and rankings are not guaranteed.
- To use a custom domain, buy a domain separately and connect it in your hosting provider settings.
